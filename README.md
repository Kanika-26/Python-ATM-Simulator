
# Python ATM Simulator

A simple command-line ATM simulation project built using Python.

## Features

- PIN-based login system
- Maximum three login attempts
- Check account balance
- Withdraw money
- Deposit money
- Change PIN
- View transaction history
- Input validation
- Exit option

## Technologies Used

- Python 3

## Concepts Used

- Variables and data types
- Conditional statements
- While loops and for loops
- Lists and append()
- User input and validation
- Basic type conversion

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python atm.py
```

## Purpose

This project was created to practise Python programming fundamentals and understand how basic ATM operations can be simulated using code.

## Note

This is an educational project and not a real banking application.
